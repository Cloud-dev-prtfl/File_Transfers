Core Application Functionality

The application's scope is defined by seven primary functional domains, with a primary focus on the user's booking and tracking journey.

User Booking Journey (FR 2.0)

The delivery initiation workflow is the most critical user interaction, guiding the user from initial request to final confirmation in a seamless modal experience.

FR 2.1: User clicks prominent "Order Delivery" CTA.
FR 2.2: An inline booking modal is initiated.
FR 2.3 - 2.5: User enters Pickup & Drop-off addresses with autocomplete and optional multi-stop support.
FR 2.7: System executes an instant price calculation.
FR 2.6 & 2.8: User selects a service tier and provides package details.
FR 2.9: User confirms the order and proceeds to payment.

Support & Growth Channels

The application provides dedicated interfaces for user support, partner onboarding, and business inquiries to foster growth and user trust.
