Zoho Flow Data Enrichment

Automated pipeline using ChatGPT & Lusha to enrich missing CRM records.

1. Zoho CRM Trigger

Module Entry Updated

Fires when Trigger Enrichment checkbox is marked as True.

2. AI Research (ChatGPT)

OpenAI App

Passes Company & Name to GPT-4o-mini to scour for generic Website, Phone, and LinkedIn data.

3. Parse AI Response

Custom Function

Deluge script converts OpenAI's stringified JSON output into usable Flow variables.

4. Is Data Still Missing?

Logic: Decision

Checks if critical fields (e.g., Phone/Email) are still empty after the ChatGPT step.

YES (Still Missing)

5a. Lusha API Fallback

Send HTTP Request

Sends a GET request to Lusha's Person API using CRM variables to find verified contact data.

6a. Update Zoho CRM

Module Entry Update

Saves Lusha's verified Email/Phone. Sets Trigger Enrichment to false.

NO (Data Found)

5b. Update Zoho CRM

Module Entry Update

Saves the AI's retrieved Website/Phone. Sets Trigger Enrichment to false.
